# Charmander, Charmanderer? (Charm Renderer) 

A custom render engine made for use in [Charm](https://github.com/MontagueM/Charm/tree/delta/EOF)

## Supports
- Statics
- Entities
- Investment Gear

## Includes
- Mostly game accurate global lighting (sky lighting with sun shadows)
- Atmosphere/Sky objects (Scene world)
- Gear shader viewing
- Entity object channel editing
